## 4. Анализ ER-диаграммы (`docs/ER-diagram.pdf`)

- **Формат:** Mermaid (`erDiagram`).
- **Соответствие `schema.sql`:** все 15 таблиц, внешние ключи, PK, связи 1:N — отражены.
- **Рассинхрон с `models.py`:** связь `SALES_ORDERS → PRODUCTION_ORDERS` (поле `sales_order_id`) на диаграмме **закомментирована**, т.к. в `schema.sql` этой колонки нет. После добавления `ALTER TABLE production_orders ADD COLUMN sales_order_id ...` — связь можно раскомментировать.
- **Рекомендация:** добавить в `schema.sql` колонку `sales_order_id` и раскомментировать связь, чтобы диаграмма полностью соответствовала и модели, и схеме.
